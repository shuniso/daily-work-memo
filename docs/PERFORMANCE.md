## Phase 0: Iced TextEditor spike（`examples/spike.rs`）

`cargo run --release --example spike -- <行数>` で、1行約100バイト（日本語・英字混在）のダミーテキストを読み込んで計測。
起動時間はプロセス開始〜最初のフレーム描画、RSS は `ps`、アイドル CPU は `top` の 2 秒間隔サンプル。

| レンダラ | 行数（≒サイズ） | 起動〜初回描画 | RSS | アイドル CPU |
|---|---:|---:|---:|---:|
| wgpu | 0（初回 cold） | 3.9 s | 25 MB | 0.2 % |
| wgpu | 0（warm） | 0.28–0.36 s | 42 MB | 0.1 % |
| wgpu | 1,000（≒100 KB） | 0.53 s | 37 MB | 0.2 % |
| wgpu | 3,000（≒300 KB） | 0.76 s | 106 MB | 0.2 % |
| wgpu | 10,000（≒1 MB） | 1.5–1.9 s | 246 MB | 0.1 % |
| tiny-skia | 0 | 0.35 s | 95 MB | 3.2 % |
| tiny-skia | 1,000 | 0.55 s | 100 MB | 5.0 % |
| tiny-skia | 10,000 | 1.46 s | 299 MB | 5.1 % |

- 初回 cold の 3.9 s はビルド直後の初回起動（OSによるバイナリ検査・シェーダ初期化を含む）。2回目以降は 0.3 s 前後。
- tiny-skia（CPUレンダラ）はカーソル点滅の再描画で数%の CPU を使う。wgpu が使えない環境でのみのフォールバックとして残す。
- アイドル時は 0.1〜0.2 %。常時 polling はしていない（カーソル点滅の再描画のみ）。

## 手動確認（macOS, 2026-09-30）

System Events によるキー入力で確認した項目。

- 日本語IME（ローマ字かな）で入力 → 確定文字が保存される
- 日本語入力モードのまま `Cmd+K` → `m` で「メール」が即挿入される（IME に食われない）
- `Cmd+K` → `↓↓` → `Enter`、`Esc` で閉じてそのまま入力継続
- `Cmd+Z` / `Cmd+Shift+Z`
- `Cmd+Shift+C` でクリップボード内容と日次ファイルが一致
- 入力直後の `Cmd+Q`（3回）・閉じるボタンで、最後の入力まで保存される
- 保存先を書き込み不可にして閉じる → 1回目は終了せず警告、2回目で終了
- 保存先を書き込み不可にして入力 → Cmd+Q（Cmd 押下の 50ms 後に Q）→ 最後の1文字まで `recovery/` に退避される
- 保存失敗の通知が出てもエディタのフォーカスが外れない

## Go / No-Go

**Go（条件付き）**。

- 起動・アイドル CPU・通常サイズ（〜100 KB）の RSS は予算内。
- macOS の日本語 IME 入力は動作。
- **既知の制約:** 日次テキストが数百 KB を超えると RSS が予算（150 MB）を超える（300 KB で約 106 MB、530 KB で約 174 MB、1 MB で約 246 MB）。Iced/cosmic-text が全行のレイアウトを保持するため。1 日分の業務メモは通常 数 KB〜数十 KB なので v0.1 では許容し、実運用で問題が出たら toolkit を再評価する。
